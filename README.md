# Algo-itseo

A dedicated dashboard for tracking and analyzing technical interview preparation. Algo-itseo helps you organize your study habits, log coding problems, and visualize your progress over time through an intuitive, retro-inspired interface.

## Key Features

- **Preparation Logging:** Systematically log LeetCode problems, mock interviews, and study sessions. Tag entries by topic to easily identify areas for improvement and track recurring mistakes.
- **Visual Analytics:** Monitor your consistency with daily activity graphs and visualize your proficiency across different concepts using interactive radar charts.
- **Confidence Tracking:** Self-assess your performance on specific problems using a quick, visual confidence rating system.
- **Goal Management:** Stay on track with a built-in Mission Panel for managing daily and weekly study objectives, alongside countdowns for upcoming interviews.
- **Community Hub:** Share your milestones and view progress updates from other users in the community feed.
- **Retro-Inspired UI:** A clean, structured interface with distinctive borders, colors, and interactive elements designed for focus and readability.

## Tech Stack

- **Frontend:** React 18, React Router, Vite, Tailwind CSS
- **Backend:** Express.js, Node.js
- **Database:** Turso (LibSQL)
- **Authentication:** JWT, bcryptjs
